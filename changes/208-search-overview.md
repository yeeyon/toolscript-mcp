- `search_tools` with an empty query now gives one line for each server, with its tool count and first 5 names, in place of a summary of every tool (issue #208). A query that is exactly a server key, or `mcp__<key>__`, lists only that server: a summary of each tool, or every name when the server has more tools than `limit`, so another server's tool can no longer rank above it and no list is cut with no note. The lines hold names, keys and counts only, and a key with another word ranks as before.
