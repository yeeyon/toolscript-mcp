- `init` imports the user-scope servers of Codex (issue #86). It reads them from `codex mcp list --json` and `codex mcp get <name> --json`, or from `config.toml` when `codex` is not on `PATH` or a call fails. It maps `env_vars`, `bearer_token_env_var`, `http_headers` and `env_http_headers` to `${VAR}` references, and turns `enabled_tools` and `disabled_tools` into policy rules that are never looser than Codex. It prints the Codex steps: the TOML entry of toolscript with `default_tools_approval_mode = "approve"`, and `codex mcp remove <name>` for each server. It leaves out `http_headers_helper`, the timeouts and each key that it does not know, with a printed reason, and never prints a literal value of `env` or a header. Two clients with the same server in another key order are now the same entry, not a conflict.
