- A refusal of a guarded folder in a long text now names the lines of the match, such as `(in content, line 306)` or `(in content, lines 12, 40, 306: each names a guarded folder)` (the first 10, then ` and more`), so a program that writes a long file through a nested call fixes the right lines in one round trip. The check is as strict as before, and the refusal still carries only numbers, never the text.
